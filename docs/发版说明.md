# 发版说明

版本号使用带 `v` 前缀的语义化版本，例如 `v0.1.0`、`v0.2.0`。发布 GitHub Release 后会并行触发容器镜像和二进制产物任务。

## 二进制产物

`.github/workflows/release-binaries.yml` 会构建带嵌入式前端的静态二进制：

```text
svnpanel_v0.1.0_windows_amd64.exe
svnpanel_v0.1.0_linux_amd64
svnpanel_v0.1.0_linux_arm64
checksums.txt
```

所有文件会自动附加到对应 GitHub Release，同时上传为 Actions 工作流产物。`checksums.txt` 使用 SHA256。

构建时会执行一次前端生产构建，然后通过 `CGO_ENABLED=0` 交叉编译三个目标。Linux amd64 产物会在附加到 Release 前执行：

```bash
svnpanel_v0.1.0_linux_amd64 -version
```

## 补传历史版本

在 GitHub Actions 中手动运行 `Release Binaries`，输入已存在且符合语义化格式的标签，例如 `v0.1.0`。工作流会重新构建并使用 `--clobber` 更新同名 Release 资产。
