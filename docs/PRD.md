# PRD：简化版 SVN 权限管理面板

## 目标

为内部 SVN 管理员提供一个比 SVNAdminV2 更小的权限维护界面，减少手工编辑 `passwd`/`authz` 造成的高风险错误。

## 用户

单个内部组织的唯一管理员。SVN 普通用户不登录本面板。

## 核心流程

1. 管理员登录面板。
2. 查看本机发现的 SVN 仓库和目录。
3. 创建 SVN 用户和分组。
4. 为用户设置单行备注和固定部门，为 SVN 分组设置备注。
5. 在仓库路径上为用户、分组或内置身份设置无权限、只读、读写。
6. 系统校验 revision、备份、原子写入并记录审计。
7. 管理员可查看用户沿父路径继承后的有效权限。

## 安全规则

- 密码默认掩码显示，登录管理员点击眼睛图标即可查看或再次隐藏，并记录审计。
- 被分组或 ACL 引用的用户不能删除；被 ACL 引用的分组不能删除。
- 遇到重复 section、重复身份或未知目标语法时拒绝写入，不进行猜测。
- 不记录密码、Cookie 或 CSRF Token。

## 验收

- 新建用户后可加入分组并在仓库路径授权。
- 原文件中的注释、未知 section 和未触及行保持不变。
- 配置并发修改返回 409。
- 删除仍被引用的用户或分组被阻止。
- 未登录用户不能查看密码，审计中不出现密码原文。
- 审计页面可按日期、动作、结果和关键词查询。
